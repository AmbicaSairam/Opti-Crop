# Team Involvement in Demonstration

## 1. Team Organizational Structure
The execution and presentation of the Opti-Crop project were managed by coordinating roles, maximizing productivity and technical polish.

## 2. Roles & Contributions Breakdown

### Project Manager / Lead presenter
- **Responsibilities:** Led requirements scoping, managed project sprints, drafted the timeline planning, and organized the final demonstration script.
- **Deliverables:** Empathy Maps, Customer Journey, Demo Script, and Project Planning.

### Machine Learning Engineer
- **Responsibilities:** Handled data pre-processing, cleaned phosphorus outliers, trained the Logistic Regression model, generated elbow charts, and compiled validation metrics.
- **Deliverables:** Model files, ranges pickling, performance evaluation reports.

### Full-Stack Developer
- **Responsibilities:** Set up the Flask application, initialized SQLite database tables, wrote parameterized queries, and integrated session handlers.
- **Deliverables:** App logic, database controllers, schema script.

### Frontend UI/UX Designer
- **Responsibilities:** Created CSS style sheets, established the modern visual theme, and designed the responsive input forms.
- **Deliverables:** CSS code, HTML layouts, design templates.
